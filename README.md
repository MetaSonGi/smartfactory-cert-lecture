## 개요

스마트팩토리 생산자동화 관련 국가기술자격 3종의 필기·실기 대비 학습 사이트입니다.
NCS(국가직무능력표준)의 능력단위 체계를 참고하여 과정·강의자료·연습문제를 구성했고,
출석·진도율·퀴즈·AI 학습 도구의 LMS 기능을 탑재했습니다.

| 자격증 | 필기 | 실기 |

| **자동화설비기능사** (구 생산자동화기능사) | 자동화요소 제어 기술 — 객관식 60문항/60분, 60점 이상 | 생산자동화 실무 — 작업형 4시간, 60점 이상 |
| **자동화설비산업기사** (구 생산자동화산업기사) | 기계요소설계·공유압·자동제어 각 20문항/90분 — 과목당 40점 이상, 평균 60점 이상 | 자동화설비 실무(기계설계작업+PLC제어작업) — 작업형 약 4시간 30분 |

## 기능

### 📖 학습 (로그인 없이 열람 가능 범위 — 현재는 로그인 후 이용)
- 자격증 → 필기/실기 → 과목별 강의 자료 (NCS 연계 표 + 핵심 정리)
- 과목별 연습문제 10문항 — 자동 채점 + 해설 표시, 재응시 가능, 최고기록 저장

### 👩‍🏫 강사
- **승인 관리**: Google 로그인한 학생 승인 → 반 배정, 반 이름 변경·삭제
- **출석 관리**: 회차 생성, 학생별 출석/지각/결석 처리
- **반 학습 현황**: 진도율·출석률·연습문제 완료율 표
- **퀴즈 출제**: 객관식 직접 출제 + 공개/비공개 전환
- **과제**: 과제 내기, 제출 현황, 🤖 AI 피드백 생성·저장
- **🤖 AI 퀴즈 생성기**: 주제 입력 → Gemini가 객관식 생성 → 검토 후 등록
- **🤖 AI 설정**: Gemini API 키 + 수업 지식(추가 자료) 저장

### 🧑‍🎓 학생
- **내 학습**: 진도율(과목 열람+연습문제), 출석률, 연습문제 평균, 과목별 체크리스트
- **출석하기**: 당일 회차 셀프 체크인
- **내 퀴즈 기록**: 연습문제 최고기록 + 강사 출제 퀴즈 응시
- **💬 AI 학습 도우미**: 과정 강의 자료를 바탕으로 질문 답변
- **과제 제출**: 링크/Git URL 제출, AI 피드백 확인

## 기술 스택

- 정적 사이트 (index.html + style.css + app.js + data/*.js), GitHub Pages
- Firebase Authentication (Google 로그인) + Firestore (hina-class 프로젝트 공유)
- Gemini API (BYOK — 사용자가 각자 무료 키 입력, localStorage에만 저장)
- 외부 이미지 없음 — CSS·SVG·이모지만 사용 (hotlink 없음)

### Firestore 보안 규칙

**규칙 변경이 필요 없습니다.** 사용하는 모든 경로가 기존 metasongi-class의
`firestore.rules`로 이미 커버됩니다.

| 사용 경로 | 규칙 |
|---|---|
| `users`, `teachers`, `config/*`, `classes` | 기존 규칙 그대로 |
| `classes/{id}/sessions`, `.../attendance` | 기존 LMS 규칙 |
| `classes/{id}/quizzes`, `.../quizResults` | 기존 LMS 규칙 (연습문제 결과는 `isPractice: true`, 재응시 허용을 위해 문서 ID에 타임스탬프 포함 — 학생 create 전용 규칙과 충돌 없음) |
| `progress/{uid}/views/{과목ID}` | 기존 진도 규칙 (과목 ID를 viewId로 사용, 신규 컬렉션 아님) |
| `assignments`, `submissions` | 기존 규칙 |

수료증(`certificates`)·화이트보드(`boards`)·자료(`materials`)는 사용하지 않습니다.

### 비용

- GitHub Pages, Firebase Spark(무료), 모두 무료 할당량 내에서 운영됩니다.
- **Gemini API는 BYOK 방식**이라 사이트 운영자에게 API 비용이 발생하지 않습니다.
  강사·학생이 각자 [Google AI Studio](https://aistudio.google.com/apikey)에서 무료 키를 발급받아
  브라우저에 입력하면, 각 키의 무료 할당량으로 AI 기능이 동작합니다.

## 저작권·법적 고지

- 본 사이트의 강의 자료·연습문제는 **NCS를 참고하여 100% 자체 제작**한 학습용 콘텐츠입니다.
  **실제 기출문제·공개문제·시중 교재 문구는 포함되어 있지 않습니다.**
- NCS는 **명칭·코드·체계만 인용**했으며, 수행준거는 요약·재구성하여 작성했습니다
  (NCS 문서 전문을 복사하지 않았습니다).
- 이미지·도면 등 외부 저작물은 사용하지 않습니다 (CSS·이모지만 사용).

> 비공식 학습 지원 사이트로, 한국산업인력공단(Q-Net) 및 NCS와 무관한 개인 제작 콘텐츠입니다.
> NCS 명칭·체계는 국가직무능력표준(고용노동부·한국산업인력공단)을 참고·인용했습니다.

## 과목 추가 방법 (개발자용)

1. `data/courses.js` — `CERTS`의 해당 자격증 `parts[].subjects`에 과목 id 추가 (형식: `{영문약어}-{w|p}{번호}`, 예: `ae-w4`)
2. `data/lessons.js` — 같은 id로 `{ id, certId, part, title, examInfo, ncs[], summary[] }` 추가
3. `data/quizzes.js` — 같은 id로 10문항 배열 추가 (`{ q, choices[4], answer(0~3), explain }`)
4. 진도율·체크리스트·AI 지식베이스는 과목 id 기준으로 자동 반영됩니다.

## 로컬 테스트

```bash
cd ~/workspace/github-projects/smartfactory-cert-lecture
node --check app.js && node --check data/courses.js && node --check data/lessons.js && node --check data/quizzes.js
python3 -m http.server 8000  # http://localhost:8000 (데모 모드로 동작)
```

Firebase 미연결 시 데모 모드(강사/학생 데모 버튼)로 전체 기능을 체험할 수 있습니다.
